# 학교폭력 ON!

학교폭력 사안처리 기록·이행·보고를 돕는 Windows PC 앱입니다.

**[최신 설치파일 받기](https://github.com/yookssam/school-violence-on-releases/releases/latest)**

## 처음 설치하기
1. 최신 배포 페이지에서 `school-violence-on-windows.zip`을 내려받습니다.
2. ZIP 전체를 문서 폴더 등 원하는 위치에 압축 해제합니다.
3. `학교폭력ON.exe`를 실행하고 본인 보관함 암호와 계정을 설정합니다.
4. 복구 코드를 따로 안전하게 보관하고 학교·담당교사를 설정합니다.

## 기존 버전에서 처음 전환하기
1. 새 ZIP을 기존 설치 폴더와 **다른 새 폴더**에 압축 해제합니다.
2. 작성 중인 기록을 저장한 뒤 새 폴더의 `학교폭력ON_업데이트도우미.exe`를 실행합니다.
3. 기존 설치 위치를 자동으로 찾습니다. 찾지 못하면 기존 `학교폭력ON.exe`를 선택합니다.
4. 기존 위치의 프로그램만 바뀌고 다시 실행됩니다. 기존 보관함 암호로 잠금을 해제합니다.

**기존 data 폴더를 복사하거나 덮어쓰지 마세요.** 도우미는 기존 자료 위치를 그대로 사용합니다.

## 다음 업데이트부터
앱 왼쪽 **앱 업데이트 → 업데이트 확인 → 최신 버전으로 업데이트**를 누릅니다.

배포자 서명·파일 검증 → 암호화 자동 백업 → 프로그램 교체 → 재실행 순서입니다. 재실행 후 보관함 잠금을 다시 해제합니다. 새 버전이 시작되지 않으면 이전 프로그램으로 돌아갑니다. 인터넷이 필요하며, 호환되지 않는 자료 형식은 자동 설치하지 않습니다.

제작자가 검증된 새 버전을 이곳에 게시하면 같은 링크에서 받을 수 있습니다. 소스 수정만으로 모든 PC가 바뀌지는 않으며 각 사용자가 앱에서 설치 버튼을 누릅니다.
